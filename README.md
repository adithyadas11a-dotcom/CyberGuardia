# CyberGuardia

AI-powered Cyberbullying and Phishing Detection Platform built using Django and Machine Learning.

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning

## Features
- Cyberbullying Detection
- Phishing Detection
- User Authentication
- Admin Dashboard
- Blog Platform
- Advertisement Management

## Project Structure
- Frontend: HTML, CSS, JavaScript
- Backend: Django (Python)
- Database: SQLite
- Machine Learning: Cyberbullying & Phishing Detection

## How to Run

```bash
git clone https://github.com/adithyadas11a-dotcom/CyberGuardia.git
cd CyberGuardia
pip install -r requirements
python manage.py runserver
```
